# SPC700 p-code emulation cases. One case per line:
#   name | P | code | init | expect
# code: bass 65816-style syntax (data/languages/spc700.arch), statements separated by " ; ",
#       "@x" is a label local to the case. make_emu.py places case i at $0400 + $40*i and
#       appends "stp"; the emulator runs from the case start to that stp.
# P: initial PSW.P decode context. init/expect: REG=hex (A X Y SP YA, flags CF ZF IF HF BF
#   PF VF NF), mem:ADDR=bytes, mem16:ADDR=@label (little-endian label address).
# Flags not listed start at 0; SP starts at $1EF.
